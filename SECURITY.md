# Security Policy

## Supported Versions

Security updates and patches are applied to the latest code on the `main` and `dev` branches as well as official release tags.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| Latest Tag (v*)  | :white_check_mark: |
| `main` / `dev`   | :white_check_mark: |
| Older releases   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **Echo Live Music Visualizer**, please report it responsibly:

1. **Private Reporting**: Submit a private advisory via GitHub's [Security Advisory Workflow](../../security/advisories/new) or contact the project maintainers directly.
2. **Do Not Disclose Publicly**: Please refrain from opening public issues or sharing details publicly until a fix has been developed and published.
3. **Response Time**: Maintainers will review and acknowledge security reports within 48 hours.
